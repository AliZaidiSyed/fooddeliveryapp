# 🍔 Food Delivery App

A Flutter-based food delivery application that allows users to browse food items, place orders, manage their profiles, and track their order information. The application includes Firebase integration and an admin interface for managing users and orders.

**Repository:** [Food Delivery App](https://github.com/AliZaidiSyed/fooddeliveryapp)

## ✨ Features

### 👤 User Authentication
- User registration and login
- Firebase Authentication
- Profile management

### 🍽️ Food Ordering
- Browse available food items
- View food details and prices
- Place food orders
- View order information

### 💳 Wallet and Payments
- Wallet screen for payment-related functionality
- Stripe payment integration

### 📦 Order Management
- View orders and order details
- Manage order status
- Cancel eligible pending orders

### 🛠️ Admin Panel
- Manage registered users
- View and manage customer orders

### 📱 User Interface
- Flutter-based mobile interface
- Bottom navigation
- Separate screens for login, signup, home, profile, wallet, and orders

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Flutter | Mobile application development |
| Dart | Programming language |
| Firebase Authentication | User authentication |
| Cloud Firestore | Database and order management |
| Stripe | Payment integration |
| Provider | State management where implemented |
| Git & GitHub | Version control |
